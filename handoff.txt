── KNOWN GOTCHAS ───────────────────────────────────────────────
  • /opt/netmind/NetMindDesktop (binary) is STALE — launch script
    skips it and runs python3 directly. Don't confuse them.

  • QAction.triggered emits a bool argument. Any slot connected to
    it must accept it: def _quit(self, _=None) not def _quit(self).

  • App runs as root. Never hardcode /home/mahdi in app code paths
    unless it's XAUTHORITY or the user's desktop file. Use /root/
    for app data (/root/.netmind/).

  • When editing /opt/netmind/core/*.py — those have matching .so
    files. The app imports whichever Python finds first. Since both
    exist, .so takes priority. To test .py changes in core/, either
    delete the .so or do a Cython rebuild.

  • Backend (Render free tier) cold-starts after inactivity.
    First push may take 15-30s. Status shows 'connecting' until
    it responds — this is normal.

  • If cloud sync shows "Checking connection…" still (shouldn't
    happen now), the _status_poll_timer fix is in set_profile()
    at line 1095-1107 of NetMindDesktop.py.
