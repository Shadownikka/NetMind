── KNOWN GOTCHAS ───────────────────────────────────────────────
  • App runs as root. XAUTHORITY must be /home/mahdi/.Xauthority
    (not /root/.Xauthority) or the GUI won't display.

  • QAction.triggered / QPushButton.clicked emit a bool. Slots must accept it:
    def _quit(self, _=None) not def _quit(self).

  • webbrowser.open() silently fails as root — browsers refuse to run as root.
    All URL-opening uses the module-level _open_url() helper instead.
    It detects the real user via PKEXEC_UID, then runs:
      runuser -u <user> -- env DISPLAY=... XAUTHORITY=... xdg-open <url>
    Never call webbrowser.open() directly anywhere in the app.

  • Grafana is ungated (free + paid). It runs locally in Docker so it can't
    be truly blocked — the button is available to everyone.

  • core/ .so files take priority over .py when both exist.
    To test .py changes in core/: delete the matching .so first.

  • Backend cold-starts after inactivity (Render free tier).
    First push may take 15-30s — "connecting" status is normal.

  • If /opt/netmind gets wiped (e.g. uninstaller test): restore with
      git show <commit>:netmind-source-code.tar.gz > /tmp/backup.tar.gz
      sudo tar -xzf /tmp/backup.tar.gz -C /opt/netmind/
      sudo cp /tmp/NetMindDesktop.py /opt/netmind/NetMindDesktop.py
      sudo cp /tmp/uninstaller.py /opt/netmind/uninstaller.py
    Then rebuild: bash ~/Desktop/NetMind/build.sh
